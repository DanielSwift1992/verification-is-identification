# Press · substitution and replay contract 0.2

The question is a transition of one declared slot under an explicitly named chord of linear triples. The complete input is `arguments`, UTF-8 `state` and `dictionary`, their two diagnostic paths, and an ordered optional array `definitions: [{path,text}]`. Imports do not fetch definitions. A missing declaration needed by a bound is an addressed refusal before publication. Unbounded triples retain free structural atoms; this contract does not assert compilation of the resulting Swift program.

The owner is `Sources/Court/Press.swift`. Its declaration and lexical reader is `StructuralSource`, also used by `ApplicationCourt`; its complete term reader and simultaneous substitution are `DefinitionReduction`. The old `Press.Term` adapter remains for existing court clients; the unused permissive `Press.parseTerm` has been removed; `Press.Term` and `serialize` remain for those clients. Rule names are identities, comments cannot supply or override an alias, and an unread term suffix cannot be an atom. The selected enum must contain exactly the three nongeneric aliases `Slot`, `From`, `Into`. A slot is a constant name, with the existing `Slot` suffix convention; the state is exactly one nongeneric top-level alias of that name, and no other nominal or alias of that name may occur anywhere in the dictionary or definitions. A second place refuses at its own path and line even for unbounded triples. Only its RHS byte interval is replaced. Public aliases, semicolons, whitespace, nested comments, multiline terms, CR, LF and CRLF are read by the shared grammar. Carried bytes outside that interval remain identical.

Generic parameters occurring in From are bound by the linear match; the others are supplied in declaration order by `Rule<...>`. Every declared bound and where equality is substituted before the transition and submitted to the existing application calculus. Its single Derivation has an exact set of root goals and one checked dependency graph; roster membership, root applications and Press bounds all use this representation and replay. Membership uses its conformance, prerequisite and reduction rules. There is no Press alphabet or company membership table. The selected rule's declared bounds are established; arbitrary constraints on its Into expression and executable members are not proved. Rule-declaration compilation, when required by a consumer, is a separate question.

`contract.json` registers 238 named input/result cases, including the five hostile classes and legal neighbors, and supplied-certificate attacks. `Checks/press-contract.py` binds the manifest and all fixture bytes, checks exact state bytes, addressed refusals, and the replay flag where declared. The fixture suite is regression evidence, not the admission argument. The general argument and its premises are in [calculus.md](calculus.md). Revision 2 retains the original 52 cases and adds 11 named reading forgeries (F7c, H3, G1–G4 and leading-comment variants in state/definitions) and ten legal comment neighbors. Integration adds duplicate-slot-place and separate-slot-place: an alias beside a same-named nominal is ambiguous; a different declared name is its legal neighbor. These observations do not establish the general argument; in particular the former induction omitted its base, allowing F7c and H3.

## Certificate and replay

Successful linear applications and lawful no-ops return `certificate` and `replayed: true` through `Checks/press-contract/main.swift`. `Press.apply` calls `Press.replay` before returning; the native command prints the certificate after its status line. The public library replay method accepts a certificate and the complete input plus proposed output. In the JSON adapter, a request with `certificate` and `output` invokes replay only, without finding a match or deriving a bound. Malformed JSON is a transport error; a semantic replay failure returns unchanged input and an addressed refusal. A refusal is non-admission with an address, not a proof that every interpretation of the source is inconsistent.

`vi.press.linear-certificate/1` carries invocation, ordered input hashes, reading certificates, slot and half-open UTF-8 byte interval, an entry for every chord member, and optional selected index. Each entry names the rule and sigma, and either a constructor-disagreement path or a finite application-calculus proof of its substituted bounds. A disagreement path uses argument indices, and `-1` for a field's owner. The empty path denotes a disagreement at the root; a nil path denotes a complete match. The checker verifies all members and rejects more than one match. It checks old = From[sigma], new = Into[sigma], instance bindings, complete variable coverage, bounds and the entire proposed output, including carried bytes.

Each input hash is SHA-256 of `u64be(path.utf8.count) || path.utf8 || u64be(text.utf8.count) || text.utf8`, without Unicode or newline normalization. The ordered input list is state, dictionary, then definitions. Reading certificates contain lexical words with raw-byte ranges and top-level grammar-production token ranges. Replay compares them with the judgement of the complete original input by the accepted T0084 scanner and the one strict production reader, from byte zero to EOF. This includes the leading-comment induction base; submitted intervals cannot restart comment state. Reconstructed declarations feed StructuralSource(readings:), not a decoded AST or a second declaration parser. The given reader/replayer's correctness is an explicit premise; its procedural P4 debt remains T0084. Certificate JSON is not canonical byte output: set and graph enumeration order is immaterial to replay.

The reader claims the declared structural fragment, not all Swift. The shared `@resultBuilder` declaration annotation is carried without claiming builder execution. Unknown attributes and unknown top-level forms refuse. Press and roster can carry direct raw literals, including escaped delimiters; raw interpolation is conservatively refused. Extended regex and a non-comment slash without following ASCII whitespace refuse throughout the input, including carried bodies and ordinary interpolation. The non-roster token/projection paths retain main's refusal of all raw literals, as does the Rust structural port. This does not admit a top-level value or a literal member of a selected triple. Roster uses the same declaration grammar and separately restricts its member/carrier relation. Balanced bodies outside the selected triple remain carried syntax; their value semantics are unchecked, with their token and byte intervals retained by the declaration production. The shared grammar's lexical and local production rules are part of the given court, not an external compiler or a printer round-trip. A future change to that grammar must preserve or explicitly version this reading relation.

## Revision 8: scalar identity through replay

Revision 8 binds all triple and proof names to `WhereJudge.sameName`, Unicode-scalar equality, including certificate fields and map keys. R1, R4 and R5 refuse canonically equivalent but differently spelled slot, rule and argument names; R0 replays unchanged. The historical WordGuard remains a diagnostic with both addresses, not the basis of matching or replay. Literal operations append/rubout/clear are outside that guard and the triple certificate until step B; their earlier source-editing debt remains. U+037E in notation is named in calculus L117 as debt T0084.

`ScalarName`, `NameSet` and `NameMap` derive equality and hashes from `WhereJudge.sameName`; expressions, obligations and continuation shapes compare their name components by that same function. This compares written name components; source ownership and context still determine declaration binding. It does not identify declarations in different modules merely because their names have the same spelling. The literal route now uses scalar equality for its slot prefix too; its line reader, comment handling and segmentation remain step-B debt.

Court certificate JSON is decoded through `CourtJSON.decoder()`. Its injective key transport precedes Foundation’s canonical String-key table, while preserving the existing wire spelling. NameMap unwraps that transport; default JSONDecoder refuses name maps rather than silently collapsing two scalar-distinct keys. Encoding a map with canonically colliding keys conservatively refuses with the word diagnostic. Existing CLI and contract-host call sites use this codec. This is an API admission change for callers decoding name maps directly, not a new certificate format. The decoder/encoder implementations remain named correctness premises; the finite key controls do not prove them.
