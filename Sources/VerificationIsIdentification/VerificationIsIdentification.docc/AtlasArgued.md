# Which edges carry their argument

An edge of the lattice says one claim rests on another. The paragraph
that argues an edge carries a record beside its prose:

> Argues: ``Unique`` needs ``Monotone``.

This page is the count of those records against the edges the lattice
declares. A record naming an edge the lattice does not declare fails the
check outright, so a paper cannot argue a lattice that does not exist.
An edge with no record waits: the count of waiting edges measures how
much argument is still prose without an address.

The build enforces 5 edges of 2396 premises (<doc:AtlasAblation>), so
for almost every edge the argument is the only thing that needs it.
This page is where that need becomes a record, edge by edge. Seeding
starts with the two chains under review, identification and matter.
