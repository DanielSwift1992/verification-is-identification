# Witness and module priority · release 1

This finite contract declares two rules of the Swift source fragment. In a concrete nominal conformer, an explicitly declared typealias or nested type is the witness of an inherited associated requirement with the same name. A reference inside that conformer binds to its own member; the requirement remains a declaration in the binding graph and is not a competing reference target. Protocol defaults do not become concrete witnesses. No inferred witness or nearest lexical shadowing rule is added.

An unqualified top-level declaration in the current module precedes homonyms in imported modules, including supplied intrinsic roots. The same root priority applies to inheritance and extension headers. Two imported roots remain ambiguous. Resolving an extension through a local typealias is outside the fragment: that local declaration prevents choosing an imported nominal homonym and produces an addressed refusal. Explicit module-qualifier ambiguities and generic carrier boundaries remain unchanged.

The cases cover alias and nested witnesses, current-module priority, a numerical question using the same bindings, and refusals for an inferred witness, two imports and a generic carrier. The alias and module cases carry both the complete binding certificate and an explicit redirection to the inherited requirement or imported homonym. Replay must reject either redirection at its source occurrence. The native compiler observation concerns the source program; it does not validate a supplied binding certificate.
