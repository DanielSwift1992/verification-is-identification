# Generic native Drawing controls

Run `python3 Checks/drawing.py`. Each request compiles in isolation against Notation, Alphabet and DocumentKit, then reads the declared root's typeName. The suite compares seven SVG files byte for byte and requires four named native refusals. Compiler failures, timeouts and unrecognised crashes fail the law.

These controls were taken from showcase 354c505. They contain the shared engine's independent cases. World receipts, the palette projection and the published Drawing contract remain with showcase until their migration slices. This suite does not replace that pinned contract.

`DocumentKitDemo` is the separate executable that generates the kit's documentation and examples. `FontMetrics` reads the licensed Inter source; `python3 Checks/documentkit-artifacts.py --write` regenerates the thirteen declared projections.
