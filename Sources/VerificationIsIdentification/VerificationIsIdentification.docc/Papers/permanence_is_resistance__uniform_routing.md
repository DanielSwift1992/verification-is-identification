### M65

**M65 (uniform interpretation and recoverability derive the two frame operations).** The I/S family need not enter only as an enumerated list. Suppose, for every set A, a total operation T_A maps A×A to A×A. Require it to respect every interpretation h:B→A of the two-marker set B={0,1}: T_A(h(0),h(1))=(h×h)(T_B(0,1)). This requirement says how the operation relates across contents. It is stronger than invariance under bijective renaming, because h may identify the two markers.

Write T_B(0,1)=(i,j). Its coordinates must belong to B. For arbitrary x,y in A choose h(0)=x and h(1)=y. The required equation then forces T_A(x,y)=(h(i),h(j)). The one generic probe therefore determines the whole family. Exactly four families remain: (x,x), (x,y), (y,x), (y,y). Each respects every such interpretation. If T_B is also injective, the first and last families are excluded: the first merges (0,0) with (0,1), and the last merges (0,1) with (1,1). The only remaining families are identity and crossing. Both recover every addressed pair, with crossing its own inverse. Recoverability plus this uniformity thus derives the exhaustive I/S class.

This is an elementary instance of the established parametricity method, discussed in [Wadler's Theorems for Free](https://homepages.inf.ed.ac.uk/wadler/topics/parametricity.html). The argument above states its own precise interpretation equation and proves the classification directly. It does not infer that every Swift generic declaration or arbitrary `PredicateReading` conformance satisfies that equation. The static corpus supplies the identity and crossing inverses through M58. `FirstSelectionTwice` and `SecondSelectionTwice` in `Checks/RoutingFrame.swift` use existing projection readings to exhibit the two other branches' mergers and positive source contrasts. The classification over all carriers is the mathematical proof here, not a compiler enumeration of arbitrary Swift programs.

The uniformity premise matters. On bits, the reversible operation (x,y)↦(x,x XOR y) is its own inverse, but it is neither identity nor crossing. Its action on (0,1) is (0,1), while its action on (1,1) is (1,0). Interpreting both generic markers as 1 would require (1,1), so it fails the displayed equation. M30 already supplies this internal reversible bit operation. No source outside the whole is needed for it. Merely requiring closure or recovery therefore does not establish content-independent frame transport.

The same proof classifies any fixed positive finite arity n. Use n generic markers and demand transport under every interpretation of them. An operation Aⁿ→Aⁿ selects one input marker for each output, giving nⁿ uniform selection families. Recovery excludes an omitted input position: two binary inputs differing only there would merge. All n positions must therefore be selected, and with n outputs each appears once. Exactly the n! permutations remain. For n=4 this derives the twenty-four routing laws already used by VI. For fixed permutations, k prepared binary probe patterns identify every routing exactly when their combined k-bit signatures distinguish all n input positions. Repeated signatures allow an undetected exchange of two positions. Distinct signatures recover every output's source address. Thus the minimum is k=⌈log₂n⌉, and n=4 needs two patterns. These statements classify the stipulated uniform interface and fixed probe occasions, not arbitrary data-dependent mechanisms that happen to match the patterns.

M65 identifies a possible bridge from declared law lists to derived law classes. A mechanism carrying only the placement of two uninterpreted contents has these four uniform possibilities, and recovery leaves two. A mechanism that uses further internal relations among those contents can admit other operations. The next realization question is which internal structure establishes uniform interpretation at an interface, and which content relations the interface can actually use. Calling all operations relational does not make every one a content-independent routing operation.

**Renaming invariance still permits an equality-controlled reversible rule.** This distinguishes the uniformity premise from independence of content names. On triples from any set A, define

```
F_A(a,b,c) = (b,a,c)   if c=a or c=b,
             (a,b,c)   otherwise.
```

The condition is unchanged by exchanging a and b, so F_A applied twice is identity. Every injective interpretation h preserves and reflects the two equalities, hence F commutes with h on these triples. In particular the rule respects every bijective renaming. It uses only an internal equality relation, with no designated content value, discarded input or exterior control.

On a carrier with three distinct elements, it is not any fixed permutation of positions. It fixes (a,b,c) when all three differ, which would force that permutation to be identity. Yet it exchanges (a,b,a) when a≠b. A noninjective interpretation exposes exactly the missing premise: start from three distinct markers 0,1,2 and let h(0)=h(2)=0, h(1)=1. Applying F and then h gives (0,1,0), while applying h and then F gives (1,0,0). The interpretation changes an equality relation that the rule actually uses. Thus recovery and independence of names do not imply M65's transport under interpretations that identify contents. Here h compares content interpretations at the interface. A physical implementation of an identification would have its own complete-record requirements.

`ThirdMatchesFirst` and `ThirdMatchesSecond` bind the equality to actual repeated source fields and compute the exchange. Their sequential compositions recover arbitrary A,B in either direction, including A=B where their answers coincide. `ThirdOutsideZeroOne` supplies the unchanged distinct-marker preparation in the finite numeral grammar. The checks positively distinguish the changed first coordinate after marker identification, and reject both treating that branch as identity and returning through a mismatched source. These clauses certify the stated witnesses. The total set-theoretic rule and its invariance are proved above, without claiming that Swift decides equality for every arbitrary content type.

This locates a constructive foundational question: which relations can an interface inspect, and which transformations preserve those relations? Equality access already changes the law family while retaining reversibility and relational naming. To obtain the fixed-routing classification, the interface must obey the stronger interpretation condition, including the displayed identification. To admit equality-sensitive rules, preserve that relation in the interface contract. Neither choice needs a source outside Ω. The same question recurs in IiS18–IiS19, where admitted quantum effects constrain which distinctions an encoding may identify.

**The data can eliminate the branch question.** Write S(a,b,c)=(b,a,c). The equality-controlled F agrees with S exactly on triples with at most two distinct contents. If a=b, the identity and swap branches already give the same tuple, regardless of c. If a≠b and at most two contents occur, c must equal a or b, so F takes the swap branch. Conversely, on three distinct contents F returns (a,b,c), and S changes its first coordinate. This identifies the complete agreement domain, rather than just a collection of successful binary probes.

Within that domain no equality test, branch tag or fact distinguishing F from S is needed to compute the whole output. The same projection reading S serves both laws. `SwapFirstTwoTriple` exposes that consumer with only the data tuple as its input, using the existing projection and joint-reading constructors. The domain has the three covering source schemas (a,a,b), (a,b,a) and (a,b,b), with a=b also permitted. `TwoContentEqualityRoutingNeedsNoGuard` derives agreement with S on all three schemas for arbitrary A,B. It compares the identity action on the first schema and the actual two match clauses on the others with the independently constructed swap reading. Coverage follows from the preceding argument. No conformance that only names a two-content domain is introduced. The distinct-marker reading supplies a positive contrast, and a refusal rejects extending this agreement to the law's action on that preparation.

This agreement also survives every finite continuation composed from F and S without a preparation that introduces a third content. Each operation preserves the present content set, and their restrictions to this domain coincide. Induction on the continuation length gives the same intermediate and final tuples, including when the next choice depends on an earlier observed tuple. Thus additional tuple readouts from these runs cannot identify which law supplied an application. If the candidate family is already restricted to {F,S}, one known all-distinct preparation distinguishes them. The need for that preparation concerns the law question. It adds nothing to computing their shared output on the two-content domain. This applies the question-scoped sufficiency of VC82–VC84 and the continuation closure of VC15 to a conditional rule: saturation can remove the need to resolve a condition altogether.

**An internal reserve can extend the preparation interface.** The new preparation need not obtain its third content from outside the whole. `InternalProbeWorld` contains the law address, the locally used pair (0,1), and a resident reserve value 2. Existing projections and `JointEvidence` prepare (0,1,0) by reading the first local address twice, or (0,1,2) by reading the reserve for the third output. Both preparations use the same actual source within each law case. `InternalPreparationsDoNotReadLawAddress` derives identical preparations for arbitrary law addresses at the same reserve value, so choosing the probe does not require knowing the hidden law. `OldInternalFactDoesNotReadReserve` also derives the same old fact for arbitrary reserve contents. The law applications read the first output coordinate in one shared question vocabulary. The old fact is 1 for both laws. The reserve preparation gives 0 under F and 1 under S, so that new fact identifies the member of the stated two-law family.

`TwoResidentReadings` supplies the actual acquisition path: both prepared instruments occur in its initial whole, the first reading records its answer, focus exchanges the resident instruments, and the second reading records its answer. `TwoResidentAnswers` derives readback from the final pair of facts. The existing generic retention equalities in `Checks/ResidentProbePair.swift` preserve the whole source and the first instrument's acquired record through the second reading. No new exchange or memory protocol is needed. `OldInternalRecordDoesNotDistinguishTheLaws` checks equality of the actual first facts, and `NewInternalRecordDistinguishesTheLaws` separates the new recorded answers. A refusal attempts to feed the old preparation to the distinct-marker law clause and fails its actual input equation. If the third resident address instead carries 1, both new facts still agree, as `AThirdResidentAddressDoesNotSupplyAThirdContent` checks. A third address and a third content distinction play different roles.

This construction changes an internal reader's accessible evidence while retaining the reserve and earlier source inside the same whole. Its initial whole explicitly supplies the second prepared instrument and its reserve-reading path. Mere existence of a reserve somewhere in Ω would not establish that path. The earlier closure result concerns continuations restricted to the two-content preparation interface. Bringing this resident preparation into use changes that scope without introducing an exterior source or invalidating the earlier result on its stated domain.

The reserve contrast belongs to the preparation contract. If its value is instead unobserved and may vary, the new output fact 1 is compatible with F using reserve 1 and S using reserve 2. `UncalibratedReserveLeavesTheNewLawFactAmbiguous` proves these facts equal. The old fact cannot resolve that difference because it does not read the reserve. Existing `TwoResidentAnswers` can instead acquire the actual reserve reading and the new law response from one source. `InternalCalibratedEquality` and `InternalCalibratedSwap` produce the same calibration fact for reserve 2 and distinct response facts. Their readback uses only the recorded pair. A refusal combines calibration from reserve 2 with a response from reserve 1 and fails the common-source equation. This supplies calibration within the whole when it was not already established, rather than treating an address or an earlier successful output as evidence of probe contrast.

**Choose the preparation, not only its output question.** `ChannelOf` records context and question. The old and new preparations above have the same channel address, so the earlier `SelectedTraceExtension` admits both under the same question-selection policy. `AQuestionAddressDoesNotSelectThePreparation` derives identical prepared inputs for those two indexed relations, and the actual responses differ. Their supplied reading witnesses specify different applications. A channel record alone does not identify that implementation or select its preparation. VC58's original beta case supplies a particular reading family, so this observation restricts its generalization rather than invalidating that case.

`SelectedResidentTraceExtension` adds the missing occurrence relation using the existing finite candidate-path grammar. A resident catalogue contains the actual old and new readings. A selection must start at that catalogue, and its selected reading must use the trace's actual source. The policy reads only trace memory and returns the selection's path address. The resulting relation is the existing `PreparedTraceExtension` beside the retained catalogue and policy, so these appear at both endpoints. For a fixed finite catalogue, one path address determines one leaf: each left/right component chooses the corresponding branch until the leaf is reached. Thus the policy's answer fixes the actual supplied reading rather than just a question shared by several readings. Arbitrary conformances outside that constructor grammar do not establish the path interpretation.

The concrete policy consumes the recorded calibration value 2 and chooses the second catalogue occurrence. `InternalInstrumentPolicyDoesNotReadTheLaw` proves the complete policy reading is identical for the F and S cases. Their selected acquisitions yield the distinct expected facts. Refusals reject selecting the old occurrence, selecting from the other source's catalogue, or composing this policy with a recorded repeated reserve value. Selection follows from available memory and the catalogue placement. It does not infer the usefulness of an arbitrary catalogue from an address alone.

The stopping outcomes now separate by question. The old two-content output is already computable by the shared decoder, with no law acquisition. The law question with calibrated reserve 2 has a distinguishing available preparation. With calibrated reserve 0 or 1 and only the declared preparations and F/S continuations, the law question remains unidentifiable: the two laws have identical tuple readouts throughout the closed two-content domain. This last conclusion is a certificate about the current interface, not a recovered law answer. Successful reuse requires a recovered answer.

For the explicit six-case domain {F,S}×{0,1,2}, suppose the two allowed new queries are the reserve reading and the first response to preparation (0,1,c), each counted once. Reading the reserve first and reading the response only when c=2 returns either the law or the stated non-identifiability certificate in at most two queries. Two are necessary in the worst case: reserve result 2 still leaves two laws, while response result 1 leaves both an identifiable S/2 case and an unidentifiable F/1 case. The old fact is constant and cannot help. This proves a worst-case count for these queries without a probability prior. It gives no optimal ordering for different costs or expected-cost objectives.

**A finite test of the missing interpretation relation.** Fix positive finite arity n and a total family F_A:Aⁿ→Aⁿ that commutes with every injective map between content sets. A tuple determines a partition π of its n positions: positions share a block exactly when their contents agree. Let B_π be the set of blocks and t_π its canonical tuple, whose i-th entry is the block containing i. The finite collection of outputs r_π=F_Bπ(t_π), one for each partition, determines the family.

Indeed, each tuple x has a unique injective map j:B_π→A assigning each block its actual content. Then x=jⁿ(t_π), and the assumed symmetry gives F_A(x)=jⁿ(r_π). Conversely, any such collection defines an injectively natural family by this equation. Thus relation patterns replace enumeration of arbitrary content values. This conclusion requires compatibility across injective embeddings, including into larger carriers, rather than renaming within one fixed carrier alone.

**Recovery within the equality-sensitive family.** Suppose each F_A is bijective. Its inverse family G also commutes with every injective h: compose F_B ∘ hⁿ = hⁿ ∘ F_A with the two inverses. Both families return only contents present in their input, since each input is the image of its canonical tuple under its support embedding. Applying this observation to F and G shows that F preserves the set of present contents exactly. It need not preserve their multiplicities or which positions agree.

Let Pₙ,ₖ be the partitions of n positions into k blocks, and let S(n,k) be their number. Each r_π must use all k input blocks. Its equality pattern ρ therefore belongs to Pₙ,ₖ, and its entries give a bijection from the output blocks to the input blocks. Invertibility makes π↦ρ a permutation of Pₙ,ₖ: the inverse pattern map recovers π. Conversely, any such permutation, with a block bijection chosen at each π, defines a bijective family through the reconstruction above. Its inverse uses the inverse pattern permutation and inverse block bijections. This classifies all recoverable families under the injective-interpretation premise.

Consequently the number of these families is

```
∏_{k=1}^n S(n,k)! · (k!)^{S(n,k)}.
```

For triples, S(3,1)=1, S(3,2)=3 and S(3,3)=1, giving 1·48·6=288 families. M65's stronger interpretation condition leaves six. The difference is freedom to act differently on equality patterns, not an exterior controller. For example, exchange the repeated and singleton contents on the first=second pattern, (a,a,b)↦(b,b,a), and leave every other pattern unchanged. This is an involution, including the all-equal case where it changes nothing. It exchanges the multiplicities of a and b while preserving the full recoverable input. A frequency of occurrence is therefore not, by itself, the conserved information of this interface.

Within this known reversible family, exact identification by prepared-input queries with complete output readings needs one query in every pattern with at least two blocks. These queries suffice by the table reconstruction. They are necessary because, at any unqueried such pattern, one can change its block bijection alone and retain both reversibility and every other response. The all-equal pattern has only one possible response and carries no law distinction. Thus triples require four queries of distinct equality patterns in this query model, even with adaptive choice. Probes restricted to two available content values can never inspect the all-distinct triple pattern and cannot identify its action. This is a limitation of the preparation interface, not of the number of repeated observations. It also explains why the five-row certificate below checks one automatic equation in the declared family: that row verifies its supplied source and answer, rather than separating candidate laws.

There is an entropy consequence at arity four. Exchange the patterns (a,a,a,b) and (a,a,b,b) for a≠b using the indicated content correspondence, and leave the other patterns unchanged. This is an injectively natural involution. If an internal reading chooses one of the four positions uniformly, its content distribution changes from (3/4,1/4) to (1/2,1/2). Its entropy increases from 2−(3/4)log₂3 to 1 bit. The strict inequality follows from 3³>2⁴. The inverse decreases it again. Meanwhile the entropy of any finite probability ensemble on complete tuples is preserved by the involution, since the probabilities are only reassigned to different complete tuples. Histogram entropy for a position reading and ensemble entropy for the complete source measure different questions. Neither a conserved histogram nor monotonic histogram entropy follows from reversible internal change. No thermodynamic identification or exterior reservoir is used here. `ChangeMultiplicity31To22` and `ChangeMultiplicity22To31` construct the two source-bound clauses from existing projections, and the generic return checks recover both preparations for arbitrary A,B. The zero/successor witness distinguishes their changed third coordinate. The case A=B returns the same tuple and has no histogram contrast.

**A finite return certificate.** Let F and G both commute with every injective interpretation. It suffices to establish G_Bπ(F_Bπ(t_π))=t_π for every equality pattern π. Transport along the support embedding gives G_A F_A=id for every A. For finite A, F_A is an injection of a finite set Aⁿ into itself, hence a bijection with inverse G_A. Thus F_A G_A=id there too. Every tuple over an arbitrary A is supported on a finite subset, so embedding naturality transports this second equality to every A. A finite one-sided return certificate therefore establishes both-sided recovery for these families, without separately requiring the second return.

`EqualityPatternsRecoverTheirPreparedContents` supplies the five return equations for the earlier equality-controlled rule through existing `ReadingFactors`. Its independent question reads the actual prepared contents. The observation applies the rule, and the decoder applies its match clauses to the actual output patterns, which can differ from the input patterns. It derives recovery of all five preparations. A refusal replaces this decoder by identity on the same observed input: source binding succeeds but answer recovery fails. The passage from these finite equations to arbitrary carriers is the proof above under the two embedding premises. The construction does not assert those premises for arbitrary Swift conformances.

**Compatibility with identifications.** Let δ be the discrete partition, with all n positions distinct. The family commutes with every map of content sets exactly when, for every π,

```
r_π = q_πⁿ(r_δ),
```

where q_π sends each distinct generic marker to its π-block. Necessity applies the claimed uniformity to q_π. For sufficiency, r_δ selects an input position for each output. The displayed equations make every r_π use those same positions, with coincident contents identified. The preceding reconstruction then makes F that fixed selection family on every carrier, which commutes with every map. This yields a finite certificate for M65's stronger condition within the stated injective-symmetry family. Recovery then selects the permutations by the earlier proof.

For n=3 there are five patterns: all equal, one of three possible equal pairs, and all distinct. The equality-controlled rule fails the displayed equation on a pair pattern, with the actual witness above. Checking only the all-distinct pattern leaves that dependence unresolved. These are exact equations about a declared law family. A finite set of empirical matches does not establish that an unknown mechanism obeys the symmetry premise. The useful reduction is from arbitrary interpretations to a finite set of relation-preservation obligations once that premise is established.

**The finite pattern certificate in types.** `TripleMarkerProfiles` contains the three input positions, each carrying its five canonical interpretation values. Existing `SelectCandidateLeaf/Left/Right` paths select actual profiles from that same support. `TriplePatternImages` reads their columns and constructs all five predicted output triples. The caller supplies positions, rather than five independently chosen expected answers. Repeated positions are permitted here because the uniformity theorem includes non-injective selections. Recovery is a further obligation.

`TriplePatternCertificate` compares this computed table with an actual `PredicateReading` assembled from five applications by `PairedApplication`. Its source must contain precisely the five prepared inputs, each paired with the same law address. The swap certificate uses existing projection and joint-reading constructors to compute the independent applications. The equality-controlled table has the identity answer on distinct markers but a positively different first coordinate on the first=third pattern. Its certificate fails there. Another refusal changes only the law address of the all-equal row, retaining every answer, and still fails the common-source requirement. A selection from a different support fails too.

The certificate checks these finite source and answer equations. Its selection domain is the existing finite candidate-path grammar, and the global conclusion uses the injective-interpretation premise proved sufficient above. Arbitrary `Pair` conformances are not selection proofs, and an address shared across supplied readings does not establish stationarity of an unknown physical apparatus. Within the declared family, however, the finite table now has a type-checked compatibility certificate instead of five unconnected reported outputs. No runtime comparison or protocol named uniformly proven is introduced.

**The constructed consumer supplies its own uniformity.** Once the five compatibility equations are satisfied, the distinct-marker answer identifies each selected position: the three markers are different. Every other row is its prescribed interpretation image. Thus projection to that one answer is injective on compatible tables and suffices to reconstruct their answers. The five-row obligation establishes compatibility. It need not remain the consumer's memory payload. This is the question-scoped reduction of VC84 applied to this certified family.

`TriplePatternCertificate.Record` composes the actual five-pattern reading with projection to its distinct-marker answer. `AcquireAnswer` records that three-position signature. `TriplePatternCertificate.Use` accepts this fact beside a new arbitrary data triple. Its three data selections must start from that triple's actual candidate support and carry the same path addresses as the certificate's three marker selections. `ReadTripleThroughPaths` returns their selected payloads. Thus the consumer's source includes the required signature fact, and the law positions remain fixed when data values change. `AcquiredPatternLawAppliesToArbitraryData` composes actual acquisition with this consumer and derives the same output as the independent generic swap reading for arbitrary A,B,C. The acquisition's source still binds all five prepared applications. Its fact payload retains one triple.

Uniformity of this generated consumer follows from the path grammar, without inferring it from sampled responses. Interpret payloads by any function h, keeping the candidate-tree branches. At a leaf, selecting after interpretation gives h of the original selected payload. A left or right path preserves its branch choice and applies the child's same relation. Induction proves that selection commutes with h for every finite path. It remains valid when h identifies payload values: their occurrence addresses remain distinct. The address equalities in `Use` bind the marker and data paths, so all three outputs obey M65's stronger interpretation equation.

This supplies the requested structural exclusion of equality-dependent routing for this interface. The admitted consumer chooses by the certified address, and no path constructor changes that address after inspecting a payload. A refusal supplies three equal data values and substitutes the wrong first path: identical current answers do not satisfy the unequal address types. Another supplies a different signature with the same context, question and triple shape. It fails the required fact input. A compact signature suffices after certification, whereas observing that signature alone does not establish compatibility of an unknown law. The construction establishes uniform use of certified positions. Applying it to that other mechanism requires a binding to this grammar or the stated symmetry family.
