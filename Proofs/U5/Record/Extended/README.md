# T0121 · запись и доказанный проверяющий U9–U11

Основание — [continuation-record-v1](../../../../Contracts/Court/continuation-record-v1/README.md) и принятые U9/U10/U11 этого Lake-проекта. Schema 3 описывает Image, необязательное C и скрытую семью T → U; schema 4 — форму Output, Question, C и парные привязки. --repeat читает прежнюю schema 2 с обязательной непустой H; optional G не является утверждением U7. §12 на физическом носителе не продвигается.

[Schema.lean](Schema.lean) задаёт закрытые канонические поля и доказывает префиксное чтение писателя. Общий [Canonical.lean](../Canonical.lean) выводит read_write, write_read и обе теоремы для ByteArray из этого обратимого кодека и допуска. В мире не сохраняется входная строка; writer заново строит её из структурных полей. [Wire.lean](Wire.lean) применяет это к Image и Agreement; Returns использует неизменный Actions.World schema 2.

[Image.lean](Image.lean) связывает прочитанные Source/E, Image, C и все члены H с моделью U9: полный обход листьев, происхождение каждого выхода и его сорт, совпадение Image с членом скрытой семьи. [Agreement.lean](Agreement.lean) связывает Source/E, форму Output, Question, C и попарные адреса привязок с U10.Request. Sort namespace проходит Source, затем Output, поэтому новый недоступный сорт остаётся содержательным отрицательным вопросом. Promise — запрошенное обязательство, не источник добавленных равенств E.

[Checker.lean](Checker.lean) допускает Judgment только со свидетельством U9.check, U10.check или U11.check = true. judgment_sound применяет прежний check_sound; exit_bytes_sound связывает прочитанные байты, ту же модель, denotation полей и универсальный вывод. Для U9 проверяется точное E_P и обещание по каждому члену; для U10 — построение, глобальная нижняя граница остатка либо один из трёх отрицательных сертификатов; для U11 — сохранение E, циклы и наименьший общий счёт либо хвост. Решения по выводу Swift или таблице случаев нет.

[Payload.lean](Payload.lean) остаётся названной посылкой перевода JSON формата 9 в типизированные сертификаты. Проверяются закрытый конверт, единственная ось и побайтная привязка record. У U10 native-порядок capacity.sort лексикографический по скалярам строк номеров (0,1,10,…,2); decoder требует именно этот порядок, затем переводит список в Nat-порядок доказанного U10.check. Это не новый критерий решения; переставленный список отказывает. Десятичная арифметика U11 переводится в Nat без машинного переполнения. Отказ перевода всегда exit 2, не отрицательный вывод суда.

```sh
cd Proofs/U5
lake build
lake exe record-check --image proof.json world.json
lake exe record-check --agreement proof.json world.json
lake exe record-check --repeat proof.json world.json
```

IO читает ByteArray; проверенные входные байты сертификата печатаются без перекодирования, LF добавляется только при отсутствии. Код 0 — положительное суждение; 1 — проверенное препятствие или отказ посылки сохранения; 2 — непрочитанный вход, подделка либо предел ресурса. Отказ посылки не доказывает невозможности после её снятия. Общий список [Axioms.lean](../../Axioms.lean) включает 39 новых утверждений; допускаются только propext, Classical.choice и Quot.sound.

## Квалификация

[Tools/FixtureProbe.swift](Tools/FixtureProbe.swift) получает типизированные чтения всех 85 случаев Image/Agreement/Repeat, экспортирует их каноническим writer и сравнивает полный общий payload с путём через Swift после биективного переименования сортов. 64 случая допущены, 21 явно не прочитан. Последние представлены искажёнными записями той же отвергнутой формы; они не объявлены семантически эквивалентными произвольным ошибочным текстам. [Cases/worlds.json](Cases/worlds.json) закрепляет наблюдения и две дополнительные записи. Source является одним адресованным целым, а не новым именованным носителем для каждого вида.

[Tools/differential.py](Tools/differential.py) компилирует модуль ContinuationRecord отдельно от Court, затем экспортёр с настоящим Swift-адаптером; новый путь не зависит от лексера или Context по графу модулей. Он сравнивает RecordCourt, Tools и record-check, исходные сертификаты, четыре варианта их форматирования, 751 подделку, 37 искажений и две согласованные подмены мира. [Evidence/differential.json](Evidence/differential.json) содержит SHA входов, бинарников, каждый код и печать, всего 1141 сравнений трёх входов. Это конечное наблюдение, не доказательство реализации Swift. Прежние schema 1/2 квалифицируются отдельно; их замороженные записи не меняются.

Отношение канонических байтов и модели — Record.Canonical и Extended.*.denotes — предмет в коде: нет. Вывод U9/U10/U11 — соответствующий доказанный check_sound и Extended.*.exit_bytes_sound — предмет в коде: нет. Перевод JSON payload — долг: T0121/PayloadCodec. IO, компилятор и исполнение — долг: T0121/Execution. Соответствие Swift и конечные наблюдения — долг: T0121/Qualification. R — условные структурные вопросы U9/U10/U11; C — schema 2/3/4 и формат 9; K — конечные пары, адреса, E и полные структурные члены. Доказательство невыразимости VC23a не предъявлено, внешнее исключение не заявлено.

## Не утверждается

Физический §12, истинность объявленных E и происхождения вопроса, source-correlated R ⊆ H × X_E, исполнение скрытого выбора и контроллер вызовов, передача E_P следующему вопросу, порядок информации между выборами P, копирование содержимого, минимальность в битах, доказанность JSON payload/IO/toolchain либо полное соответствие Swift и Lean.

## Ремонт T0124

`ImageDenotes` для объявленной H теперь утверждает не только соответствие всех членов записи и модели, но и `∃ g ∈ e.members, g.image = w.image`. `image_members_include_image` выводит этот свидетель из уже существовавшего успешного допуска; вычисление допуска, прежний отказ `record.image` и канонические архивы не меняются. Усиленное соответствие передаётся существующими `Image.denotes` и `Image.exit_bytes_sound`. В общий список добавлено одно утверждение: 250 вместо исторических 249 из квитанции T0121.

Регрессия прежних входов: [schema 1](Evidence/schema1-regression.json) — 174 сравнения; [schema 2](Evidence/schema2-regression.json) — 134, без расхождений кодов и печати. [42 прежних архивов schema 1](Evidence/schema1-bytes.json) и [13 schema 2](Evidence/schema2-bytes.json) совпадают с принятыми квитанциями по SHA мира и сертификата. [Proofs](Evidence/proofs.txt) подтверждает 249/249 утверждений. В диагностике schema 1 заменён только временный префикс каталога; [исходный SHA и правило](Evidence/legacy-transport.json) сохранены.
