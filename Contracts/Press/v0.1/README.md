# Press · substitution contract 0.1

VI owns Press: `Sources/Court/Press.swift` computes a linear triple substitution or edits one literal. This release freezes 33 input → result/addressed-refusal cases in `fixtures/cases.json`, including the 27 paired browser cases from T-0041 and six additional Character controls. `contract.json` binds every fixture hash and every case ID; the driver binds the suite identifier to the manifest hash. A subset or edited suite cannot claim this release.

| Part | Identifier | Meaning |
| --- | --- | --- |
| Triple question | `vi.press.linear-substitution/1` | One slot, linear pattern, instance arguments, zero/one/multiple matching chord members. |
| Literal question | `vi.press.character-literal/1` | Append vetted Characters, clear, or remove one extended grapheme cluster with Swift `Character.dropLast`, including `𐐀`, combining marks, ZWJ, flags and Hangul in this suite. |
| Transport | `vi.press.json/1` | One UTF-8 JSON request on stdin, one JSON response on stdout; exit 0 and empty stderr for a computed result or semantic refusal. Malformed transport is a carrier error, not a semantic refusal. |
| Finite suite | `vi.press.substitution/0.1` | Every registered case, without deriving expectations from the implementation under test. |

A request carries `arguments` (the argv after `press`, without file flags), `state`, `dictionary`, `statePath` and `dictionaryPath`. A response carries `state`, boolean `changed`, and optional/null `refusal`. A refusal carries `address` and `reason`; addresses are `statePath#slot`, `dictionaryPath#rule-or-chord`, or `arguments` for missing invocation arguments. The driver checks the exact address and the declared reason fragment. A refusal must return the original state and `changed: false`. Successful states are compared without Unicode normalization; `changed` reports a byte difference, including whether an accepted literal operation is empty. A no-match is an unchanged success, not a refusal. Paths identify supplied source texts; the pure computation does not read them.

Run the owner and driver controls with `bash Checks/press-contract.sh`, or the full registered law with `./check.sh --only contract`. For a different implementation, pass an absolute executable argv prefix to `python3 Checks/press-contract.py --command-json '["/absolute/carrier"]' --implementation-id 'caller label' --report /tmp/press-report.json`. The driver never invokes a shell. Its report records actual responses, exit/stderr, timings, executable and manifest hashes. An interpreter hash does not attest the files it loads; keep source pins and a build receipt separately.

`Checks/press-contract/main.swift` is a JSON adapter over `Press.apply`, not another matcher. Its `--native` route also exposes the file command for `native-host.py`: the original 27 CLI controls plus two separate host controls (an unavailable dictionary is irrelevant to literal editing; denied atomic publication fails without announcing success or changing state). Publication is the native host's responsibility. Passing the pure suite does not grant a port atomic file publication.

This finite release does not specify arbitrary Swift parsing, malformed declarations, all Unicode versions, every possible grapheme, CRLF source handling, compiler admission of the next state, UI gestures, durability/concurrent writers or browser storage. The fixtures use LF and the current owner's bare state aliases. In particular, the browser's pre-existing public-alias and `From = Slot` convenience extensions are not certified by these fixtures; they need an owner decision and additional cases before general parity can be claimed. Contracts/Court, Drawing and the grammar laws remain independent obligations. The suite establishes parity on these inputs, not general equivalence or replacement of the browser carriers.
