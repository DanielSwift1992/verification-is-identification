# A visual reading of one construction

The four frames use the same declared three-source family. They do not present a new example or an unrestricted physical model. Coordinates are display notation for the source types: `Never → 0`, `Lit1 → 1`, `Lit2 → 2`.

| Frame | Exact source | What is shown |
| --- | --- | --- |
| 1. Declared family | [Light.swift](../../Sources/Examples/Light.swift): `RedBeam`, `RedBeamWithIR`, `EyeImage`; [Verdict.swift](../../Sources/Examples/Verdict.swift): `RedBeamWithMoreIR`, `ThreeBeamVerdict`, `DeclaredThreeBeams`, `CoveredThreeBeams` | Three distinct supplied sources have the same computed visible answer. The pictured family is exactly these three; it is not the full family of physical sources. |
| 2. Changed question | [Verdict.swift](../../Sources/Examples/Verdict.swift): `VisibleReading`, `InfraredReading`; [Seeing Is Encoding](../../Sources/VerificationIsIdentification/VerificationIsIdentification.docc/Papers/seeing_is_encoding.md), SiE3–SiE4; [VI](../../Sources/VerificationIsIdentification/VerificationIsIdentification.docc/Papers/verification_is_identification.md), U2c | The visible answer is constant. The hidden coordinate differs. The new question is not answered by the common old image. No added reading is silently supplied. |
| 3. Supplied transformation | [Verdict.swift](../../Sources/Examples/Verdict.swift): `SwapVisible`, `SwapFactors`, `SharedSwappedImage`; [Transition.swift](../../Sources/Examples/Transition.swift): `SwapTransition`; [Verdict paper](../../Sources/VerificationIsIdentification/VerificationIsIdentification.docc/Papers/verdict_is_invariant__finite_records.md), VC12 | For every `BeamShape` in the constructor's type scope, the visible image after swapping is the swap of its visible image. The picture specializes that generic identity to the same three sources. Each retains its own hidden coordinate. |
| 4. Changed operation | [Verdict.swift](../../Sources/Examples/Verdict.swift): `ExposeHidden`; [Coverage.swift](../../Checks/Coverage.swift): `FUTURE_OBSERVATION`, `SafeFutureAnswer`, `ArbitrarySwapFactors`; [Transition.swift](../../Checks/Transition.swift): `STEP_EXPOSURE`; Verdict VC12 | The old image no longer determines the visible image after this different operation. The obstruction follows from different required answers to the same input, not merely from one failed candidate decoder. |

The supplied constructors and generic equalities are established in the typed model. A calculation of their displayed coordinates is not evidence of a physical act, measured sensor response or an acquired operation. The picture names this boundary. It also preserves the original reading as a statement about its original source state; failure of a future use does not erase that fact.

The companion formal diagrams state U2c and the adequacy law from [Acquisition Keeps Its Question](../../Sources/VerificationIsIdentification/VerificationIsIdentification.docc/Papers/acquisition_keeps_its_question.md). This example does not establish all obligations of that action law. In particular, it does not acquire or execute a physical operation.

Regenerate with `python3 Documentation/Figures/beam-study.py`. The renderer uses the drawing primitives in `render.py`. Review the displayed source mapping and the existing positive/negative fixtures when changing any frame; visual agreement alone is not a semantic check.
