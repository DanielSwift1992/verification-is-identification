# Generic native Drawing controls

Run `python3 Checks/drawing.py`. Each request compiles in isolation against Notation, Alphabet and DocumentKit, then reads the declared root's typeName. Each request includes the separate owner StyleContract source beside Binding.swift. The suite compares seven SVG files byte for byte and requires four named native refusals. Compiler failures, timeouts and unrecognised crashes fail the law.

The case shapes originate in showcase 354c505. Their current binding and expected bytes are projections of the pinned gate style in Worlds/Documentation; they are regenerated and checked against this SDK. World receipts, the palette projection and the published Drawing contract remain with showcase until their migration slices. This suite does not replace that pinned contract.

`DocumentKitDemo` is the separate executable that generates the kit's documentation and examples. `FontMetrics` reads the licensed source bytes and records their owner-relative path and SHA-256 (Python 3 hashlib, also used by the authoring receipts); `python3 Checks/documentkit-artifacts.py --write` regenerates the thirteen declared projections.
