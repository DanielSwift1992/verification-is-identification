## Binding derivation and replay

`judge where-bindings <sources...> --context <context.json>` issues an ordered array of `vi.court.context-name-bindings/1` derivations, one for each own source question. `judge replay-where-bindings <certificate.json> <sources...> --context <context.json>` checks every question and edge against the same byte-bound inputs. The commands also accept the report's `--document <source>` view selection. `judge where <sources...> --context <context.json> --report --bindings <certificate.json>` makes the ordinary verdict replay that supplied derivation before judging its demands. The proof file is included in the report's input hashes. Existing report fields and commands without this option retain their transport shape; a fresh binding derivation is replayed internally for context/2.

Each derivation names its selected own source and lists every source input/module/import row, original SHA-256 and admitted-view SHA-256, every indexed declaration place and position, and every selected nominal reference's view range, source line, owner chain and full declaration place. The declaration table supplies each target's address. Offsets explicitly refer to the line-preserving view, not to raw UTF-8 bytes erased by DefinitionView. The original source hash remains separately bound. Stored names, paths, kinds and written references use ScalarName; only serialization carries their strings. ContextNameBinding reads the common lexical tape. Its selected module bindings also drive WhereContextNames' rewriting; an independent nearest-owner choice supplies no result.

Replay requires complete ordered source/declaration/reference coverage and equality of each typed row against the source-derived relation. A redirected declaration, changed scope chain, omitted or added edge, changed source hash or changed view hash refuses before an equality can yield holds. `bindings.json` freezes one native-positive source question with a valid proof and seven adversarial proof mutations. Swift's source question stays positive; Court refuses the invalid derivation. This tests proof admission, not equivalence between Swift's acceptance and an untrusted certificate.

The binding relation and its verifier are part of Court. Their correctness, the common lexical judgment, and the admitted-view projection are premises of this verdict; issuing and replaying a derivation does not prove equivalence to all Swift name resolution. T0105-R retains that source-reader/correspondence debt. Physical execution and native-module correspondence retain T0105-C. The new typed derivation does not erase either debt by a finite test count.
