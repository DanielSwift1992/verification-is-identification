# Unread gated applications · v1

The owner freezes 44 complete CLI observations from the accepted T0098 merge named in contract.json, before changing application discovery. Each case binds its UTF-8 sources and the exact exit, stdout and stderr of `judge where`. The cases include qualifications and their start addresses, alias propagation, nesting, metatype line breaks, comments, literal content and interpolation code, declaration exclusions, borrowed inputs and Unicode/CRLF neighbors. These are finite regression observations, not a proof of lexical correctness or a general cost bound.

The repair changes discovery, not the relation judged: every application of a gated head outside a read span or a declaration header is reported. The ordinary declaration reader, alias closure, reduction and semantic judgments remain separately responsible for their inputs. No consumer names or task records determine this mechanism.
