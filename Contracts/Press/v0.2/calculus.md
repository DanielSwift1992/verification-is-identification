# Admission argument for the linear Press relation

This is an argument for a declared calculus, not an inference from a finite sample. It concerns finite supported structural terms and finite source readings. It assumes the given court's local lexical/structural production judgements, DefinitionReduction replay and ApplicationCourt closed-obligation replay. It does not assume the producer, pattern search, submitted certificate or printer is correct. Physical publication and the legacy literal route are outside this relation. No nonexpressibility or external exception is claimed.

Let I be the ordered input bytes and paths, A the invocation, D the declarations admitted by the reading derivation, s the unique slot alias and t its RHS term. A rule r in the named chord declares parameters V, constant slot s, linear pattern F, template G and requirements B. An instance supplies exactly those variables of V absent from F. The transition relation R(I,A,O) holds iff every named rule is admitted in this structural fragment, exactly zero or one member structurally matches t, every matched member's substituted B has a closed application proof, and O is either the original state (zero matches) or the original byte string with only the slot's RHS replaced by G[sigma] (one match). A refused bound is non-admission, even if the triple's syntactic pattern matches. A chord with two matches does not admit an output.

## Reading

Let J(B) be the given StructuralSource judgement on the complete original UTF-8 input B, at a stated diagnostic path. It either refuses with an address or derives a lexical tape L, a complete sequence U of top-level production intervals and the declarations D read from those productions. The single lexical judgement is WhereJudge.lexicalReading; scan(carrying:) only projects its addressed tape. Both retain original byte and line coordinates. Their single production reader is regions/readDeclaration, in strict declaration scope. Historical structural projection explicitly carries executable and conditional regions; a carried region does not establish the relations inside it. Roster separately judges its narrower admissible member/carrier relation. These are stated questions on the same reading. This is not a claim that all Court paths share one production reader: notationFiles still uses WhereJudge.stripComments/NotationScope and CountCourt.blocks has a production loop. Their lexical judgement is now shared; production unification remains P4 debt T0084.

A reading witness supplies L and U, not D. Replay runs that same judgement from byte zero through the end of B and requires byte-exact lexical words and spans and exact production intervals. If J is correct for the stated grammar and these comparisons are correct, equality of the complete L and U establishes that the reconstructed D is the reading of B; no correctness of the submitted certificate or match producer is assumed. This is a conditional soundness argument. Correctness of the procedural reader/replayer itself is a named premise and remains the T0084 P4 debt. Regression cases do not prove that premise.

The leading-trivia base is included in the whole-source judgement: scanning begins in its initial state at byte zero, not at the proposed first lexeme. A first lexeme inside a leading line/block comment disagrees with L. An empty proposed tape must equal the complete tape of B. Since no certificate interval restarts the lexer, adjacent-token maximality and the final suffix are likewise inherited from J(B), rather than inferred by resetting the scanner on gaps. This replaces the former sliced lexical induction; it preserves the repaired F7c/H3 boundary without retaining a second lexical reader. The lexical newline word is normalized, but every span and line is measured on original LF, CR and CRLF bytes. Delimiter recognition uses Unicode scalars so a combining mark cannot hide a quote or slash in a grapheme cluster. Regex literals and backquoted identifiers are not read and therefore refuse, including in carried bodies and ordinary interpolation. Strict reading also refuses every code directive at any depth; a carried body cannot hide an unparsed conditional branch. Raw-string interpolation remains refused by the structural modes; notation retains its previous traversal through the same state machine. Literal escapes still have to be traversed to locate their real closing delimiter; carrying a body does not waive this lexical judgement. The native host obtains UTF-8 with WhereJudge.fileText, without removing a BOM; both structural modes conservatively refuse the preserved BOM as unread code input, at its original byte and line.

The same production reader consumes the whole tape; the witness cannot omit a production, split a statement or hide a suffix. Each declaration has an origin and token interval, from which its byte address is derived. The slot has exactly one declaration across state, dictionary and all definitions, irrespective of whether the rule has bounds. Another nominal or alias of that name refuses at that declaration, before either matching or replay. Binding of the named rule and selected slot is reconstructed to the unique matching declaration region; duplicate declarations refuse where encountered. Generic variables are bound by their parameter declarations, and declared bound references are resolved through the shared StructuralSource/ApplicationCourt environment. This is not a claim that every name in arbitrary Swift is bound: unbounded Press constants still form a free structural signature, imports do not resolve modules, and balanced value bodies remain unchecked. Replacing that free-name signature with an explicit declaration-place signature is a separate binding debt, not something proved by the source hash. Distinct contents are established only by the declared equality/membership or constructor-disagreement relation, not inferred from byte inequality of declaration addresses.

## Certificate text identity

Let S be the finite sequence of Unicode scalars carried by a JSON string. `ScalarName` stores S without normalizing it; its equality is `WhereJudge.sameName`, equality of the scalar sequences, its hash consumes that sequence, and its order is lexicographic on scalar values. The same type stores reading tokens and unit kinds, Press names and substitution values, source addresses and carried literal encodings, reduction expression heads/axes and proof steps, application goal names, roster normal forms/proof text, and continuation request/constructor/leaf/sort names. Fixed schema/version/outcome tags, SHA-256 encodings, diagnostic output and validated canonical decimal counters do not name source places. String enters through reader construction or Codable serialization, not as the stored type of those source-text fields. This is a representation boundary, not a claim that a ScalarName is already a valid lexeme or bound declaration.

For a reading Unit, synthesized equality is the conjunction of scalar equality of kind and integer equality of lower/upper. Thus equality of units cannot identify a different scalar sequence merely because Swift String considers it canonically equivalent. The same argument composes through stored products and recursive sums of typed terms/goals, with positions and branch tags preserved; NameMap uses the same scalar relation for keys and typed substitution values. A newly proposed certificate is still subject to whole-input lexical/production replay and the declared semantic replay. This argument assumes the correctness of the stated scalar equality, compiler-synthesized product/sum equality and the JSON transport; the finite R6, roster and collection observations exercise those premises and do not prove them.

## One lexical form table

`WhereJudge.lexicalReading` is the one delimiter/state machine used by `blankCommentsAndStrings` and `StructuralSource.scan`. The latter only selects an admission mode and projects the tape. This table enumerates its branch families and named conservative boundaries, including the final code-scalar branch; it is not a claim to enumerate all Swift grammar or all future lexical extensions. Every row is executable contract data: `SourceLexingTests` reads the JSON source cell (a string or an explicit source/lent object) and checks all four decisions. `read` means lexical admission only; another cell names a required refusal substring. The last column of decisions additionally runs the existing conditional-production question `stripComments`. That question is not a second delimiter reader. The table controls its own declared examples, not a proof of the implementation.

`notation` retains the existing WhereJudge blanked-text question; `projection` supplies structural words without raw literals; `declarations` is Press/roster's strict mode, which admits directly delimited raw carriers but refuses raw interpolation and every code directive at any depth, including executable bodies and ordinary interpolation. A hash inside a comment or literal is content, not a directive. The attribute and built-in directive vocabularies remain the single sets in WhereJudge; unknown attributes may be discharged only by its declared-builder/lent-name judgement, with local macro shadowing. Strict production reading still refuses unsupported attributes or declaration kinds even when lexical admission succeeded. The structural code alphabet is closed: the previous Unicode alphabetic/underscore word candidates and alphabetic, numeric, nonspacing-mark, spacing-mark or underscore continuation candidates, intersected with the Swift 6.2.3 identifier-start/continuation ranges declared in SourceLexing.swift; space, tab, VT, FF and U+00A0 separators (CR/LF are separate line breaks; other Unicode whitespace refuses in code); ASCII digits; and the punctuation `(){}[],:;.=<>+-*%&|^~!?$` plus backslash. Slash, quote, hash, at-sign and backquote are classified by the earlier named branches. Other scalars in code refuse with path, line, byte and Unicode code point in both structural modes, including inside carried bodies and ordinary interpolation. This is a conservative lexical alphabet, not the full Swift identifier/operator or expression grammar. FEFF and other scalars remain literal/comment content in those states; no global byte filter is applied. Legacy notation deliberately retains its residual-scalar policy; unifying that admission policy is named P4 debt T0084, not silently claimed by the shared delimiter machine. The interpolation stack takes the newline bound from the nearest open literal, as Swift's AllowNewline.back(): code newlines, line comments and newlines inside block comments refuse under that single-line literal; a nested multiline literal establishes its own multiline bound (L74–L77). Escape values, expression validity and value bodies remain unchecked. In particular, no conclusion that every admitted carrier compiles as Swift is made; H8 is specifically a non-Swift escaped single-line newline and now refuses in every mode.

## Matching and substitution

For a linear pattern F, structural matching against a fixed t has at most one substitution for the variables occurring in F. Proof by structural induction: a variable leaf binds the whole corresponding subtree; a constant leaf requires the same constructor; an application requires the same head and arity and applies the induction hypothesis independently to each child; a field requires the same axis and applies it to the owner. Linearity gives disjoint sets of newly bound variables across the children. The remaining variables have exactly the explicitly supplied instance values. Hence the complete sigma, when it exists, is unique. No arbitrary search strategy is an admission premise.

Replay of a positive member checks exact variable coverage, instance equality and the literal structural equation t = F[sigma]. A negative member supplies a path through equal enclosing constructors to unequal heads, arities or field axes. The checker rejects a path ending at a variable. By induction back along that path, no substitution can make F equal t. Thus negative members need no search trace and cannot conceal a matching member. Applying these judgements to the entire named chord establishes the zero/one/many boundary independently of the producer's selection.

Replay substitutes sigma into each declared requirement and asks the existing closed-obligation checker to verify its finite proof. The proof must have exactly those roots and reachable obligations, each reduction is replayed, and strict prerequisite cycles refuse. Therefore a matched outside-bound value cannot reach publication merely because a later state might be compiled. Equality requirements use the same reduction calculus; they are not nominal string heuristics.

Finally, replay constructs the sole permitted output byte string from the original prefix, G[sigma] and original suffix and compares all UTF-8 bytes. This establishes the second substitution equation and prevents changes to carried material. The zero-match case compares against the entire original byte string. Taken together, the verified reading, complete chord judgement, substituted bound proof and output equation imply R(I,A,O).
