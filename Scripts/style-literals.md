# Visual style boundary

The closed serialization positions are the SVG attributes and CSS properties below. Each has literal refusal and owner-reading controls in both Swift and JavaScript. The same source is pinned by the gate fixture; no second list is authored there.

SVG: font-weight, font-size, font-family, font-style, stroke-width, stroke-dasharray, stroke-linecap, stroke-linejoin, rx, ry, r, markerWidth, markerHeight, refX, refY, orient, viewBox, d, fill-opacity, stroke-opacity, flood-opacity, opacity, color, fill, stroke, flood-color, dur, values, dx, dy, stdDeviation.

CSS: font-weight, font-size, font-family, font-style, stroke-width, stroke-dasharray, stroke-linecap, stroke-linejoin, border-radius, opacity, color, background, background-color, fill, stroke, flood-color, transition, transition-duration, transition-delay, transition-timing-function, animation, animation-duration, animation-delay, animation-timing-function, box-shadow, text-shadow, margin, margin-top, margin-right, margin-bottom, margin-left, padding, padding-top, padding-right, padding-bottom, padding-left, gap, row-gap, column-gap.

`viewBox` and `d` in this boundary select marker geometry. A canvas frame's coordinate construction and count arithmetic remain mechanisms. SMIL `fill=freeze` implements FrozenReveal's retained state; it is not a paint. Transition property names name the mechanism's state channel; durations and easing are owner values. Units and references do not choose their numeric value.

White and Black are endpoints of the Spectrum algorithm. They may participate in its halving, count and radix operations; using either endpoint directly in a visual position inside DocumentKit refuses. CoverNN and Weight names carry no numeric reading in the SDK.

The check scans every Swift file and authored DocC Markdown below DocumentKit and the shared footer template. It folds simple literal atoms, literal interpolation and literal call arguments at this edge. It does not evaluate arbitrary Swift or JavaScript programs. Ordinary words and arithmetic outside visual positions pass. Generated owner SVG/CSS have separate source/binding equality checks.
