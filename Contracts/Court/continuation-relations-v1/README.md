# Continuation with source equalities

In the U3 carrier with declared equalities this court judges the §12 question form: one continuation for every filling, or an obstruction certificate. The physical carrier of §12 is not advanced (link 1 remains open at LG28d, and the executive relation of link 2 remains open). This is U5, structural U6, U7 and U8 of VI §1c in the existing ContinuationCourt; U11 additionally assumes the supplied fixed-member repeat interface described below. The legacy type-field question, archive format 1 and its pre-loss retention mode keep their meanings. Formats 2 and 3 retain the U5/U6 meanings below; format 4 adds total-action judgments, and format 5 adds repeat-return judgments. U9–U10a are not implemented here.

The legacy command without --relations identifies occurrences by their opaque type field. On SameSortDifferentPlaces it constructs a result with no additional leaf, while format 2 certifies an obstruction for the same written request. The legacy verdict is a type-field judgment (the singleton-carrier interpretation of that comparison), not the universal U5 judgment over independently filled source occurrences.

The declared whole is (T, E): Source declares the finite product shape T, whose opaque sorts are the request's generic Structure parameters; Equalities declares E, with omission meaning the empty relation. Every leaf occurrence has its own Source path. Reusing a sort parameter does not equate independently filled occurrences. All fillings satisfying the declared E are considered under every interpretation of the sorts by nonempty sets. Declaring E describes that conditional domain; applying this result to an actual source still requires those source relations.

## The written relation

The existing StructuralSource reader reads Source, Observation, Question and the optional Equalities typealias. The existing DefinitionReduction expression grammar resolves parameters and aliases. No additional lexer, regular expression reader, value getter or parser of Swift is added. The old ReadProof leaf records a generic sort parameter; normalizing a view to that leaf loses its Source occurrence. RouteProof therefore adds a Source anchor while reusing Context, its checked constructor, DefinitionReduction expansion and the same argument-proof replay. Format 1 has residual witnesses rather than E-path or obstruction witnesses; format 2 represents this distinct question instead of reinterpreting an old archive. The shared reader's own admission remains an explicit dependency of T0084/T0083; the proofs here are conditional on that reading and on the checked fixed foundation signatures.

Every type axis of the request record must occur in a replayed source or cut derivation. An unread axis, including an unused misspelling Equality, refuses at Request.Axis instead of silently meaning empty E. Construction and replay both enforce this coverage on the live record. Source, Observation, Question and optional Equalities have the fixed roles above; additional structural helper aliases are allowed when their live definitions are actually read. Coverage is a projection of the validated read proofs, not a second parser or a search for how to use an unread field. Value implementations do not supply type axes or source equalities.

Observation and Question declare cuts of this whole: U3 operations using Source, its Left/Right projections, paired views, and supported structural aliases of such expressions. Their leaf maps go from visible addresses to Source addresses. Each visible leaf has exactly one origin by construction; two visible leaves can refer to the same origin. Pairing creates two visible branches and cannot merge two source occurrences into one visible leaf. Only a declared E-path licenses equality between distinct source occurrences. A bare sort parameter, a detached shape alias or another whole's field does not supply an origin in this Source and refuses at Request.Observation or Request.Question. The required Question is read before any candidate program is constructed.

The whole-origin admission requirement in T0088 item 6 is a task premise (the user's words on 23 October at 10:3x, “все начинается из его разреза”), not a consequence of U5. The desk summary Materials/T0089/result.md corrects the earlier derivation in claude.md: U3 itself can start from a declared form without a parent. This court admits cuts of the explicitly declared whole under that task premise; rejection of an unrooted form is not a U5 impossibility judgment.

Equalities is a pair of endpoint trees of the same product shape. Corresponding leaves form the edges of E; each endpoint must be a leaf of Source of the same sort as its partner. The path in the first endpoint tree is the stable address of that edge. An absent Equalities field means empty E; an existing field cannot be omitted from the certificate.

For example, this source relation allows either observed leaf to answer the other without identifying its contents:

```swift
enum SameSourceContents<S: Structure> {
    typealias Source = Paired<S, S>
    typealias Observation = Source.Left
    typealias Question = Source.Right
    typealias Equalities = Paired<Source.Left, Source.Right>
}
```

Multiple equalities use matching endpoint trees; the EqualityChain case declares Source.Left = Source.Right.Left and Source.Right.Left = Source.Right.Right. They are relations of source contents, not Swift same-type requirements between stored values.

## Construction and replay

Construction propagates paths through the undirected E graph from the observed source occurrences. If every required leaf is reached, it projects the selected observation occurrence and assembles the required product. It reads no contents and enumerates no candidate programs.

The finite certificate contains live-source read derivations, rooted view derivations, each required output path, its selected observation path, and its equality ground. The three grounds are structural alternatives: address identity; a nonempty path of addressed E-edges with orientation; observed value coincidence. The third is always rejected. Different addresses alone imply neither equal nor different contents.

Replay checks live-source endpoints, exact output coverage, every selected leaf's sort, equality path continuity and endpoint, and the assembled pick/pair term. It does not call derive, normalize, matching or equivalence closure. The source and route read proofs are replayed against the supplied current declarations. Hash equality is not used as a substitute for that semantic check.

If a required leaf is absent, construction returns an obstruction certificate: the missing Question path and a complete sort-respecting partition of Source leaves. Replay checks that each source leaf occurs exactly once, every E-edge stays inside a block, and the requested leaf's block contains no same-sort observation leaf. It need not find connected components or search for a decoder. Blocks may be coarser than E-components if these conditions hold.

Newly constructed obstructions additionally name the residue needed by this Question. The residue extension supplies an ordered E-forest inside every partition block and a list of the unobserved blocks addressed by Question, with all their Question leaf paths. Each forest edge must connect an already justified member to the next member at the declared E-address. Together with the closed partition this certifies the exact E-classes, without repeating graph search during replay. The needed list must cover exactly the Question addresses in classes absent from Observation; repeated appearances of one class share its entry. The block supplies the source addresses and opaque sort. A coarser counterexample partition alone never licenses identification of its distinct places as one E-class.

The needed list has canonical Question order: depth-first, left before right, with a class inserted at its first Question occurrence and its Question paths retained in encounter order. Replay intentionally rejects a permuted list even if it names the same classes and paths.

The residue extension is optional for compatibility with the original format-2 obstruction judgment. A saved obstruction without it proves only that continuation fails, and makes no claim to name the full question residue. All current constructor obstructions include the checked extension. Omitting or changing a class or Question address inside a presented extension refuses. Without --retain this remains the U5 question from Observation alone. Naming classes without a retained view and joint decoder is not a U6 plan.

## Same-source retention and U6

The --retain mode selects one Source leaf from each required E-class absent from Observation. The missing classes are those of the checked residue extension. Construction uses their Question order and chooses the first Source member of each class. Replay allows another member of the same class and a permutation of the M leaves when the view and decoder agree with that order. A balanced product of the presented leaves is the retained view M. Its view term selects the declared Source paths. The joint view is exactly Paired<Observation, M> of the same Source: Left addresses Observation and Right addresses M. No independently acquired value or second source is admitted.

Construction invokes the same U5 constructor on that joint view to obtain R. The certificate carries M's source addresses and assembled view term, the joint input selections with E-paths, and the assembled term of R. Replay first checks the original U5 obstruction, the exact class proof and all required Question occurrences; it then checks exactly one M leaf per missing class, the view term and the same U5 selection/program rules on the joint view. It performs no graph search, closure or decoder construction. An omitted class, a source path outside a leaf, a leaf of another class, an extra leaf, an invalid E-path or a changed view/decoder term refuses with its certificate address. Extra leaves are rejected because this mode claims a minimal plan, rather than merely an adequate plan.

For each missing class, U5 necessity applied to an arbitrary structural residual D requires some D leaf in that class: otherwise two fillings of a two-element interpretation agree on P and D but differ on Q. Exact classes are certified by the closed partition and its connecting forests. Hence the number of missing classes is a lower bound on added leaves, and this construction attains it. Every adequate structural D also supplies a same-class leaf for every M leaf. This is the structural minimum of U6, not a bound in bits or physical memory units.

The information claim is relative: M ≼_P D means M(x) = f(P(x), D(x)) on X_E. M factors through Q by selecting the corresponding Q occurrences up to E; composing with any adequate decoder Q = d∘⟨P,D⟩ gives this relative factorization. It does not assert an absolutely least standalone residual among arbitrary deterministic encodings; the XOR example of VI §1c forbids that assertion. The court constructs M and R in the declared U3 grammar, not a decoder for an unpresented arbitrary D.

M must still be available in that same x, or be retained as part of P's actual action. A plan does not recover an absent independent field from P alone and does not implement physical copying or acquisition. When no class is missing, M has no carrier: P alone is used, no paired empty object or opaque constant is introduced, and the original format-2 result remains byte-identical. Preservation under a family G is a separate action question below; --retain keeps its U6 meaning.

Nonempty retention plans use archive format 3. They preserve the original conclusion (an obstruction from P alone) and add retention with leaves, view, selections and program. A new number prevents an old format-2 reader from accepting the archive while silently ignoring its unchecked plan. A format-3 archive must contain retention; a format-2 archive must not. Older format-2 archives, including obstructions without the residue extension, keep their original meaning. Replay never synthesizes a missing plan from an old obstruction. A zero-residual construction stays in format 2 with no new field, so its bytes remain unchanged.

## Conditional justification

The source-rooted route rules preserve occurrence addresses by induction: the source anchor supplies all occurrences, projection selects a child, pairing combines disjoint output branches, and definition replay substitutes the actual source body with its declared argument guards. Leaves retain their sorts.

For a constructed result, address identity gives reflexivity, each E-step uses exactly its declared source relation or its symmetry, and a path composes those equalities. Each selected input therefore equals its independently required output on every filling in X_E. Product assembly proves the full required equality. This is U5 sufficiency for the stated grammar; fixtures are observations of the implementation, not this argument.

For an obstruction, use a two-element interpretation of the missing sort. Two fillings constant on the partition blocks differ only on the separated block. They satisfy every E-edge and have identical Observation images but different Question images. Hence no function of that observation alone answers both; in particular there is no universal U3 continuation. All other sorts can be interpreted by nonempty singleton sets. This is a certified refusal of the universal U5 question, not a refusal for every narrower preparation or every singleton interpretation.

For the optional class names, induction along each supplied forest proves that every member of a block is E-related to its root. Closure of every declared E-edge in the partition proves the reverse inclusion: an E-path cannot leave its block. Thus these blocks are exactly the E-classes. Direct lookup through the certified maps of Observation and Question proves the stated list of missing classes and their Question addresses. This proof concerns a fixed declared Question, not preservation of every possible future question. The leaf minimum of --retain additionally uses U5 necessity, as stated above.

The correctness of these replay rules and of their implementation remains a named premise. These rules do not prove the physical establishment of E, execution of a returned program, arbitrary Swift semantics, or equivalence with a separate port.

## Total actions: U7 and U8

The --relations --actions question uses the same declared Source, Equalities, Observation and Question. Actions declares G for U7; an absent field means the empty family. HiddenActions declares the nonempty H for the separate U8 question; if absent, no hidden-action question is asked. H need not be contained in G. A present field cannot be omitted from its read certificate. Misspelled or otherwise unread axes still refuse at Request.Axis. No unit value, artificial opaque sort or empty payload is introduced for absence.

Both families are read with the same Context, DefinitionReduction and RouteProof used for the other cuts. They are trees of Paired whose members are complete T-shaped source-rooted terms. The interpreter first obtains the product's source-address map. A node with exactly Source's shape and sorts is one member; otherwise both children must be families. A proper subtree of T has fewer leaves than T, so this boundary is unambiguous. Members keep left-before-right order and their product paths in the certificate. A malformed or unrooted term refuses at its request field; it is not a certified U7/U8 obstruction. Unlike cover-law, whose family members are named field-cuts read in domain form, Actions/HiddenActions use the first T-shaped node inside one field-cut as the member boundary; both use the same interpreter.

For example, a two-field source can declare identity and exchange without a new record language:

~~~swift
enum HiddenExchange<S: Structure> {
    typealias Source = Paired<S, S>
    typealias Observation = Source
    typealias Question = Source
    typealias Actions = Paired<Source, Paired<Source.Right, Source.Left>>
    typealias HiddenActions = Actions
}
~~~

Actions and HiddenActions each receive an E-preservation judgment. For every member, every generating E-edge's two images must have an addressed E-path. The certificate lists these paths in declared E-edge order. Checking the generators suffices by path composition, so gamma_g is well-defined on E-classes. If preservation fails, the certificate names the member and the E-edge; the exact closed partition separates its two images and certifies the absence of an E-path. This refuses reuse of the unchanged X_E premise, rather than forbidding the structural action on another domain. HiddenActions is checked independently even when absent from Actions.

U7 starts with Question's classes and closes them under the class maps of Actions. For each retained class the certificate names a Question leaf, a finite word and an E-path from its pulled-back origin to the selected representative. Words are written outermost to innermost: [g,h] means g composed with h. Pullback folds that list left to right, gamma_h(gamma_g(c)); physical application of that composite would apply h first. This is the contravariant order gamma_(g composed with h) = gamma_h composed with gamma_g. Every Question class has an empty-word witness.

The stable view V_S is a balanced product of one Source representative for each certified reachable class. Its term, representatives and order are recorded. Each image action supplies one closure target per retained class, U5 selections with E-paths, and an assembled pick/pair term g_S. A further U5 certificate constructs Question's decoder through V_S. Replay checks the exact E-partition and its connecting forests, all word pullbacks, Question coverage, every closure target and every assembled term. It does not search the graph, compute a fixed point, derive read proofs, or construct a decoder. Read derivations are replayed against the current declarations.

These checks give both inclusions needed for the least closure: words prove that retained classes are reachable from Question; empty-word coverage and all closure edges prove that every permitted pullback remains represented. U5 checks V_S after g equals g_S after V_S on X_E, and checks the current Question decoder. Induction then supplies every word-question. For any view H with decoders for every such question, the finitely recorded word/Question witnesses select every representative of V_S from H, up to the recorded E-paths. Hence V_S factors through H on its actual image, as in U7. This is informational minimality, including among arbitrary sufficient views; it is not a bound in bits. Constructing that factorization as an executable program for an unpresented H would additionally require its finitely used decoder constructions.

For a cycle g(a,b,c) = (c,a,b), a fixed first-coordinate question requires all three classes and reaches the third retained class with a length-two word. After one known g the second-coordinate question reads the original a instead. These are different questions; the court does not update a reading path using an unrecorded clock or hidden choice.

U8 uses the E-classes of Observation as S, in first-occurrence order. It updates the actual declared Observation shape, including repeated occurrences; this view and its one-per-class view factor through one another on X_E. The positive certificate gives one written program k, the common class restriction and U5 selections proving the same k for every hidden member. Different E-equivalent input projections must not become different unrecorded programs: construction fixes one program and supplies a separate E-path justification for each member.

U8 refusal (a) names an Observation leaf, a hidden member and its source image outside S. Exact classes prove that this image is absent. Two fillings that agree on S but differ on the missing class, in a two-element interpretation of that sort, require different outputs from the same held input. Refusal (b) names one Observation leaf, two hidden members and their distinct same-sort image classes. One filling distinguishing these classes requires different outputs for the same complete source and held input. Thus neither refusal can be repaired by an arbitrary deterministic k on this domain. Conversely, closure and agreement give a common structural selector; the positive certificate checks this for every member. These are the two directions of U8, conditional on the declared domain and replay rules, not evidence from sampled payloads.

The certificate separately records closureInheritedFromStableView. It is true when Observation has the same product shape and corresponding E-classes as the certified V_S, and every normalized hidden member is also a normalized member of G. In that case closure follows from U7 by construction; U8 still checks agreement and can return refusal (b). False does not assert failure of closure: the independent U8 certificate decides the question. In particular HiddenCommon and HiddenOnly need no inclusion H in G.

Only total structural actions on all X_E are admitted. Source-correlated choices R contained in H times X_E, related blocks of words J, partial actions and state-dependent availability are outside this contract. No interface executing a hidden choice is supplied. Declaring E does not physically establish it. The §12 question here has the U3 carrier with E: unknown acting content is represented by the permitted action form while the selected member remains private; the answer is a common way or a certified obstruction. The physical carrier, LG28d and the executive relation of link 2 are not advanced.

## A fixed hidden repeat episode: U11

The --relations --repeat question reads the same Source, Question, Equalities and nonempty HiddenActions using the same interpreter and the same first-T-shaped-node member boundary. HiddenActions is required in this mode; absence is unresolved input, not an empty or vacuously successful U11 family. Source/E admission, exact classes, E-forests and preservation paths use the existing U5–U8 checkers. Optional Actions is read if present for whole-axis coverage but makes no U7 claim. Observation and the original P-only U5 conclusion keep their meanings; Observation is not substituted for the source on which repetitions act.

The additional premise is one fixed unknown h in H throughout an available repeatable episode. Every call applies that same deterministic function to the current whole. Question refers to the original Source x, before an obligatory first call, and the obligation is Q(h^k(x)) = Q(x) for every h and every x in X_E, with one common positive k. It is not the different question Q(h^k(x)) = Q(h(x)). The post-first-call relation is {(h,x,y): y=h(x)}; neither h nor y is independently resampled. A repeated procedure name does not establish this premise.

Construction follows gamma_h separately from every required E-class c until its first repeated vertex. A return to c supplies that pair's least positive cycle length. A first repeat at d different from c supplies an obstruction instead. This graph is of source classes, never payload states. A positive certificate covers every pair of a declared hidden member and a distinct Question class, in member order then Question first-occurrence order. It carries each walk including the final repeated start, its length, and an arithmetic step for each length. Repeated Question occurrences in one E-class share their class; distinct declared H members keep their addresses even if they have the same source map.

Replay checks the closed partition and its E-forests, checks preservation for each H member, and reads every presented walk edge directly from that live member's source map. A walk's prefix must contain no duplicate, and a positive walk must end at its starting required class. Its length is therefore the first positive return, not just a multiple. Exact classes license these class comparisons; coincidence of values or sorts supplies no equality. Replay does not discover orbits, search the graph, compute an equivalence closure or call any constructor.

The arithmetic starts at 1 and checks each update L = previous * (length / gcd(previous,length)). The certificate supplies gcd, multiplier and resulting L; replay recomputes the Euclidean remainder/gcd and decimal multiplication and checks their exact values. Total calls must equal the resulting least common multiple, and additionalCalls must equal total calls minus one. Counts are canonical decimal strings, so a valid result can exceed machine Int. Only cycle lengths, bounded by the checked class count and proof budget, are machine integers. The common 100,000-step proof budget also bounds arithmetic work; exhaustion is unresolved and makes no impossibility claim. Existing source/depth/node and 8 MB archive limits still apply.

For a negative return certificate, the required class c and an addressed member h start a walk whose prefix is distinct, whose final vertex occurs at the recorded earlier index, and whose final vertex differs from c. Direct image checks make this a tail into a cycle without c. Therefore no positive iterate of that h returns c. Interpret that sort by two values, assign one value to c and the other to every other class of the sort, and fill other sorts nonemptily. This one filling satisfies E and disagrees with the original Question at every positive call count for that h. Thus no common positive k exists on the declared domain. Conversely, when all required classes lie on all their member cycles, multiples of the least common multiple return all Question classes by E, and every universal return count must be divisible by every first-return length. These are the two directions of U11; the fixtures do not prove them.

Failure of an H member's E-preservation is recorded separately with the existing preservation certificate and no U11 conclusion. It refuses U11's domain premise, rather than asserting a tail obstruction. This refusal makes no claim that no positive k exists: in ReturnBadPreservation the Question place is fixed by h, so one call returns Q(x) on X_E although h leaves X_E. A class graph may have tails irrelevant to Question: for h(a,b)=(a,a), a returns in one call while b never returns. For H containing (a,c,b) and (b,c,a), the first-coordinate Question needs 3 calls, whereas all coordinates need 6. For identity and exchange on a pair, one fixed hidden choice returns after 2 calls even though U8 refuses a common one-step update of the full pair; independently choosing identity then exchange would not return it.

The output is a proved repeat scheme of k total calls, k−1 after the obligatory first one. Calling an unknown function parameter requires the supplied repeat interface and is not a pick/pair operation of the original opaque-leaf U3 grammar. This court neither executes h nor builds a physical call controller or completion detector. Mutable hidden memory, restricted domains and intervening evolution are outside this judgment. If intervening evolution changes the actual step, fixed h must be established for that whole step or replaced by an appropriate joint model. Minimality here is of call count in this repeat-only scheme, not information, bits, elapsed duration or arbitrary plans. The goal is return of Q(x), not an arbitrary structural target R(x). The physical §12 carrier, LG28d and the executive relation remain open.
