# Claim checks

The corpus contains premises, relations and derivations. Experiments and
their saved results are separate from that mathematical object.

`bash Checks/receiver-continuation.sh` checks the generic sufficient recovery
case of System U12a: recovery of the original bound input makes composition
with that receiver well-formed and derives its answer. Two projections of the
recovered pair give their respective answers without a second target field.
Four separate refusals distinguish answer availability from input recovery
and reapplication, reject unjoined inputs with equal answers, and reject an
unchanged answer under an arbitrary change of receiver. This uses fresh core
and current Examples declarations; it does not establish runtime execution,
the general partial-use theorem, or truth of arbitrary open reading conformers.

`bash Checks/structural-continuation.sh` builds the native Court constructor
for the alias/product/projection fragment of System U5/U6. It checks source
admission, generated programs, exact missing-class witnesses, saved-certificate
replay and adversarial changes; then independently Swift-checks emitted generic
programs and their use by `ExchangeRetainedTargets`. It distinguishes an exact
uniform obstruction from unsupported syntax and pre-loss retention from recovery
of a discarded field. This is a type-field calculus, not a proof that two values
of the same Swift type are equal. Primary-source compilation uses a fresh core
and current Examples declarations, not a full Examples module build.

`bash Checks/least-continuation.sh` checks the generic joint decoder and
the lower factorization for `TargetFrameTransport`, against a fresh core
module and the current Examples source declarations, without a cached Examples
module or a full Examples module emission. It uses a reversed memory and
continues through the existing frame action. The U11 example also derives
return of a question after three calls and of the whole after six. Seven
independent refusals check a missing observation translation, a substituted
present question, an unjoined residual factor, an unjustified whole return,
independent substituted actions, agreement obtained by rewriting the target,
and replacing a relational promise with value preservation. They do not prove the general information lower bounds or
identity of physical memory instances; System U5–U11 states the mathematics
and its source obligations. No payload-state enumeration is performed.

For a local relation change, compile the affected generic constructors and
their nearby refusals. `bash Checks/verdict.sh acquisition` checks recording,
refinement and retained access. Use the full verdict suite when shared proof
relations change, and the grammar check for the source files being edited.
Prose edits need their relevant quote, voice or link checks.

The acquisition cases also separate a stored payload from a source reading,
and coexisting, comparable records from a uniform verdict. A named compiler
refusal concerns that attempted construction; absence of a conformance is
not a proof of its negation. Infrastructure failures supply neither result.

`bash Checks/verdict.sh localphase` checks the contact, phase acquisition,
calibration and continuation fixtures. It first creates fresh declaration
modules for both the current core and Examples in a disposable directory.
It does not borrow a cached core module or generate the modeled process's
object code. The current scope includes 56 independent named refusals.
After the combined positive check, each negative fixture is checked in its
own file; that file must also pass independently with the flag disabled.
This avoids repeating unrelated large proofs for every negative case, while
preventing missing standalone dependencies from being counted as a refusal.
`FourLeafValueQuestion.swift` adds VC100c's one-fact value decoding for all
twelve actions on (A,B,B,B), and separates it from whole-law identification.
The general query lower bound is the paper's argument, not a test result.

The historical reader checks are frozen under [WhereV2](Archive/WhereV2/README.md): 42 executable consumers and one additional native consumer have fixed hashes; this README retains only its original provenance hash. The public archived reader is a deliberate substitute for the different uncommitted reader named in 207 local historical receipts. Their separate identities and receipt addresses are recorded in the manifest. The three small archived programs remain red because the reader was substituted, not because the source questions drifted. `python3 Checks/archived-where.py` verifies the frozen bytes and scans all Checks JavaScript, Python and shell files for literal live sibling paths and reader overrides. These archived runs do not establish the current Court contract: canon v2 accepts three false claims in the five-case v0.1 comparison. Current judgments use `Sources/Court` and the versioned [Court contract](../Contracts/Court/v0.1/README.md). Unsupported syntax is a reader failure, not a proof of incompatibility.

`Context.swift`, also checked by `whole`, derives which answers survive an
expanded source family. The first coordinate and a coarser descendant remain
readable, while agreement of the second coordinate and a restatement retaining
it are refused. `Acquisition.swift` binds a published reading to the active
field of a declared root. Its archive cannot supply that application's
certificate even when both branches give the same answer to the same question.
Record Is System SW3a states the scope and application argument. There is no
separate status propagation mechanism or automatic proof of free prose.

`Saturation.swift` checks preservation of complete-image agreement by both
generators and an image path using a different equivalent representative.
`Continuation.swift` derives a future question from a present acquired fact.
Its operation remains part of the question. Separate refusals reject source
identity, substitution into an actual source path, a retargeted question and
insufficient acquired evidence. Nominal inequality alone is not a behavioral
separator.

`bash Checks/verdict.sh interactions` checks the partial guarded-swap fragment
without rerunning unrelated refusals. Its generic witnesses preserve the
source condition through the complete image, and its cases separate success
from availability, past permission from the successor condition, and equality
on shared available words from a transitive identification relation. The
mathematical domain and quotient arguments are VI VC46–VC47.

`bash Checks/verdict.sh resident` checks the memory-selected acquisition and
its actual preparation, measurement and parking seams. Generic recovery
uses output fields. The archive decoder remains source-bound after the
instrument reset, and empty or occupied reserves cannot provide a fresh slot.
The mathematical relations and slot account are VI VC58–VC59 and M45.

`bash Checks/verdict.sh construction` checks reconstruction through a retained
predecessor, one operand answer across different records, and the distinction
between a local merger and the complete record. The partial diagonal family
does not admit mixed operands. A stationary floor satisfies the open retention
equations, separating them from fresh construction. EiF EF8–EF9 supply the
general decomposition and admissibility arguments.

`bash Checks/verdict.sh boundary` checks the common-answer contract in both
directions through the existing SharedDecoder and VerdictIsInvariant relations.
Its refusals preserve the actual sources, question, encoding and orientation
of positive obstructions. The three-class binary image keeps compatibility
and the successful answer. VI VC60–VC61 prove the domain and minimum image.

`bash Checks/verdict.sh common`
checks one prepared acquisition serving two agreed resident applications,
including the actual source, reading, preparation slots and retained archive.
The same first fact can occur outside the agreement domain; VI VC62–VC63
separate conditional reuse from establishing that condition.

`bash Checks/verdict.sh evidence` checks two actual acquisitions and the
comparison of their retained memory addresses. Memory agreement derives the
source verdict, and memory distinctions derive source obstructions. The
resident second-slot seam, three images and reuse from acquired agreement
are checked with nearby refusals. The claims are VI VC64–VC65.

`bash Checks/verdict.sh evolution` checks transport through side exchange and
the exchange of the first alpha with a resident zero. It binds old acquired
evidence to the actual source step and endpoint, distinguishes the three-class
swap image from the four required initial classes for the new question, and
retains the displaced value and historical trace. VI VC66–VC67 give the proofs.

A complete premise-deletion sweep is an optional investigation of dependency
or redundancy. It is not required after each edit. Its saved report is
`Research/ablation/current.md`, outside the mathematical corpus. Its premise
list can become historical without blocking the theory's build. Numerical
experiments run explicitly with `./check.sh --research-only` and do not gate
publication of the corpus.

| Command | Evidence | Limit |
|---|---|---|
| `bash Checks/verdict.sh` | Generic Swift bodies compile and each named false fixture fails separately | Supplied readings need their stated meaning, and finite paths use the constructor grammar |
| `python3 Checks/operational_quotient.py` | Exhaustive small-state quotients, independently checked by reachable-pair search | Finite instances supplement the paper's general proofs |
| `.build/debug/Tools ablate --self-test` | Exact inheritance cuts, failure classification and restoration | Unit checks of the measurement tool |
| `python3 Checks/ablation_failure.py .build/debug/Tools` | Injected disk failure, process failure, concurrent source edit and a type-refusal control | Uses a stand-in build command in disposable packages, not a Swift proof |
| `./check.sh --only ablation` | Tool checks plus agreement of the saved experiment's premise list with the current graph | Explicit request only, does not rerun every cut or certify unchanged behavior |

A full ablation needs a fresh symbol graph and the real Swift compiler:

```sh
swift build --product Tools
swift package dump-symbol-graph
.build/debug/Tools ablate .build/arm64-apple-macosx/symbolgraph/VerificationIsIdentification.symbols.json
```

It temporarily changes one core declaration at a time. Do not edit core files
or start another core build during that run. Before the first cut it writes
complete copies into `.build/ablation-recovery/<run-id>/`, with a `sources.json`
manifest of original paths. A successful run verifies all source bytes and the
restored build, publishes the report atomically, and removes its own snapshot.
An aborted run keeps the snapshot and the previous report. A hard interruption
may require restoring the affected file from that copy. Check for concurrent
user edits before any manual restoration.

A disk error, compiler crash or failure to launch is not evidence that a theorem
needs a premise. The tool aborts on such failures. It also stops if a source
changes outside its probe, preserving that edit. The failure-injection audit
checks these outcomes and verifies that an incomplete run cannot replace the
existing report.

`ClosedInformation.swift` derives generic retention from `Permanent` and recovery of both components after two internal swaps. Separate compiler refusals reject loss of the previous record and a merger inferred from a local reset. `closed_information.py` audits all two-state maps and all four-state permutations, then checks internal reset, reversible copying and correlation-only recovery. These classical models do not derive physical unitarity, a thermodynamic arrow or an energy budget.

`closed_dynamics.py` checks exact autonomous quotients of finite reversible systems, finite observation windows, the preparation requirement for reversible copying, and locally compatible parity tables without a global assignment. `SwapWindow` has generic component recovery and update proofs. A separate gluing witness checks shared intermediate identity. These do not derive physical time, quantum contextuality or a general reconstruction algorithm in Swift.

`discovery_gate.py MODEL --output PREFIX` produces checked JSON and Markdown for a declared finite transition model. It separates shortest pair witnesses from guaranteed single-run initial-state identification. `discovery_audit.py` checks policy ranks and losing families, replays all initial states, searches shorter words independently, and checks both saved reports. It also checks an autonomous history extension with its program inside the modeled whole. This is a table analysis tool, not evidence that the table is physically complete.

A model may supply a homogeneous string or integer `question` array giving the required answer for each original state. `verdict_discovery.py` tracks `(current state, original answer)` beliefs. Same-answer mergers are permitted, conflicting-answer mergers are permanent obstructions within the declared model. `verdict_discovery_audit.py` checks 9475 small system/question combinations, all 15 target partitions of the four-state trap, and corrupted certificates. `AdvanceQuestionTag` proves tag transport in Swift, conditional on the tag's initial correctness.
