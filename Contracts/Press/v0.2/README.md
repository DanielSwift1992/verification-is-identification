# Press · substitution and replay contract 0.2

The question is a transition of one declared slot under an explicitly named chord of linear triples. The complete input is `arguments`, UTF-8 `state` and `dictionary`, their two diagnostic paths, and an ordered optional array `definitions: [{path,text}]`. Imports do not fetch definitions. A missing declaration needed by a bound is an addressed refusal before publication. Unbounded triples retain free structural atoms; this contract does not assert compilation of the resulting Swift program.

The owner is `Sources/Court/Press.swift`. Its declaration and lexical reader is `StructuralSource`, also used by `ApplicationCourt`; its complete term reader and simultaneous substitution are `DefinitionReduction`. The old `Press.Term` adapter remains for existing court clients; linear Press no longer calls its permissive `parseTerm`. Rule names are identities, comments cannot supply or override an alias, and an unread term suffix cannot be an atom. The selected enum must contain exactly the three nongeneric aliases `Slot`, `From`, `Into`. A slot is a constant name, with the existing `Slot` suffix convention; the state is exactly one nongeneric top-level alias of that name. Only its RHS byte interval is replaced. Public aliases, semicolons, whitespace, nested comments, multiline terms, CR, LF and CRLF are read by the shared grammar. Carried bytes outside that interval remain identical.

Generic parameters occurring in From are bound by the linear match; the others are supplied in declaration order by `Rule<...>`. Every declared bound and where equality is substituted before the transition and submitted to the existing application calculus. Membership uses its conformance, prerequisite and reduction rules. There is no Press alphabet or company membership table. The selected rule's declared bounds are established; arbitrary constraints on its Into expression and executable members are not proved. Rule-declaration compilation, when required by a consumer, is a separate question.

`contract.json` registers 52 named input/result cases, including the five hostile classes and legal neighbors, and supplied-certificate attacks. `Checks/press-contract.py` binds the manifest and all fixture bytes, checks exact state bytes, addressed refusals, and the replay flag where declared. The fixture suite is regression evidence, not the admission argument. The general argument and its premises are in [calculus.md](calculus.md).

## Certificate and replay

Successful linear applications and lawful no-ops return `certificate` and `replayed: true` through `Checks/press-contract/main.swift`. `Press.apply` calls `Press.replay` before returning; the native command prints the certificate after its status line. The public library replay method accepts a certificate and the complete input plus proposed output. In the JSON adapter, a request with `certificate` and `output` invokes replay only, without finding a match or deriving a bound. Malformed JSON is a transport error; a semantic replay failure returns unchanged input and an addressed refusal. A refusal is non-admission with an address, not a proof that every interpretation of the source is inconsistent.

`vi.press.linear-certificate/1` carries invocation, ordered input hashes, reading certificates, slot and half-open UTF-8 byte interval, an entry for every chord member, and optional selected index. Each entry names the rule and sigma, and either a constructor-disagreement path or a finite application-calculus proof of its substituted bounds. A disagreement path uses argument indices, and `-1` for a field's owner. The empty path denotes a disagreement at the root; a nil path denotes a complete match. The checker verifies all members and rejects more than one match. It checks old = From[sigma], new = Into[sigma], instance bindings, complete variable coverage, bounds and the entire proposed output, including carried bytes.

Each input hash is SHA-256 of `u64be(path.utf8.count) || path.utf8 || u64be(text.utf8.count) || text.utf8`, without Unicode or newline normalization. The ordered input list is state, dictionary, then definitions. Reading certificates contain lexical words with raw-byte ranges and top-level grammar-production token ranges. Replay checks every lexical production, maximality at adjacent boundaries, trivia-only gaps, contiguous production coverage, true statement boundaries, and each local structural production. Declaration search is untrusted; semantic declarations are reconstructed by those local grammar judgements, not accepted from a serialized AST. Bounds consume these replayed declarations through `StructuralSource(readings:)`, without another file read. Certificate JSON is not canonical byte output: set and graph enumeration order is immaterial to replay.

The reader claims the declared structural fragment, not all Swift. The shared `@resultBuilder` declaration annotation is carried without claiming builder execution. Other attributes, raw strings and unknown top-level forms refuse. Balanced bodies outside the selected triple remain carried syntax; their value semantics are unchecked, with their token and byte intervals retained by the declaration production. The shared grammar's lexical and local production rules are part of the given court, not an external compiler or a printer round-trip. A future change to that grammar must preserve or explicitly version this reading relation.

## Carriers and remaining work

The unchanged v0.1 suite remains required and its 33 expectations are not rewritten. Literal append/rubout/clear retain v0.1 behavior; they return no linear certificate. Their declarative replacement, including the alphabet/segmentation premise, is explicitly the unimplemented step B of T0083. No universal P3 claim is made for that legacy route.

The browser carrier in gate remains pinned to v0.1 and has not been repaired in this vi-only change. Its separate reader, ignored bounds, slot-as-pattern extension and absence of replay are the port debt recorded under T0083 in the desk package. A v0.1 pass is not a v0.2 claim. There is no Press implementation in the Court Rust sample; its where/count port is a different question. No wasm Press equivalence is asserted.

Run `bash Checks/press-contract.sh` to compile the same Court sources once for the adapter and run v0.1, v0.2, driver controls and native host controls. Explicit bound definitions for the native command are repeatable `--definitions <path>` inputs. No ambient module lookup, sibling checkout or network is used by Press.
